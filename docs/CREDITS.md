# Asset provenance

The SVG wallpaper, icon artwork, panel backgrounds, Aurorae artwork and concept
composition were created specifically for DreamUI. Their editable sources are in
`tools/build_assets.py` and `tools/build_preview.py`.

The supplied screenshots are aesthetic references only. No Microsoft logos,
Windows icons, wallpapers, sound files or fonts are bundled. KDE's installed
Breeze theme and widgets provide fallbacks; their files are not copied into this repo.

The repository did not specify a license at initialization. A distribution license
for DreamUI's code and artwork should be chosen by the repository owner before a
public release intended for redistribution. No third-party license is implied.
